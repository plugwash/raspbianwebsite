# Raspberry Pi SD Card Performance

The SD card performance on the Raspberry Pi is very slow. Over time, it
will be important to Raspbian to maximize to the extent possible the
performance of the SD card media on the Raspberry Pi. For now, below is
a collection of links that address this subject and will be explored
further in the future.

  - [Flash Memory Card
    Design](https://wiki.linaro.org/WorkingGroups/Kernel/Projects/FlashCardSurvey?action=show&redirect=WorkingGroups%2FKernelConsolidation%2FProjects%2FFlashCardSurvey)

  - [Optimizing Linux for Flash
    Memory](http://www.raspberrypi.org/phpBB3/viewtopic.php?f=9&t=850)

  - [Optimizing fs on sd-card for Linux/Fedora on
    Dreamplug](http://blogofterje.wordpress.com/2012/01/14/optimizing-fs-on-sd-card/)

  - [SD Card performance in R-Pi onboard
    slot](http://www.raspberrypi.org/phpBB3/viewtopic.php?f=2&t=5057)
