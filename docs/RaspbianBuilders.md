# Raspbian Autobuild System

This page may eventually document the Raspbian automated build system.
For the time being, it just links to the web interface for the buildd
system of the new build cluster and the logs from the old decommissioned
build cluster.

  - <http://buildd.raspbian.org/status/>: buildd web interface for the
    new build cluster including status information and logs.

  - [Build Logs](http://archive.raspbian.org/raspbian/logs/main/): logs
    of all packages built by the old (decommisioned) build cluster.
