# Raspbian Bug Reports

If you've noticed something that doesn't work properly while using
Raspbian, let us know. The problem you have discovered is likely to
affect other users as well. The sooner we know about the problem, the
sooner we're able to fix it.

**Before You File a Bug**

Please note that many issues in Raspbian may already be reported in the
Debian bug base. If so, it would help the Raspbian Team enormously if
before you enter a bug that you first [check to see if a bug report has
already been filed with
Debian](http://www.debian.org/Bugs/Reporting#filedalready). Please
include a link to any existing Debian bug along with your bug report.
Links to email archives discussing the bug within Debian may be helpful
as well.

  - **[Report A Bug](https://bugs.launchpad.net/raspbian)**
