# Raspbian Autobuild System

This page will eventually document the Raspbian automated build system.
For the time being, it just links to the list of packages the autobuild
system failed to build and the associated log files.

  - [Build Logs](http://archive.raspbian.org/raspbian/logs/main/): logs
    of all packages built by the automated build system

  - [Build Attempted List](/BuildAttempted): updated list of automatic
    builds that failed
