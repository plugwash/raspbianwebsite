# Raspbian History

This document sets out some key dates in the development of Raspbian and
some analysis of postings to the RPi forums.

At the moment the document only analyses events recorded in the original
Raspbian thread (Debian Hard Float (armhf) for RPi) although there are
other key events in newer threads so this must be considered a work in
progress.

## Progress of the repository

![repository progress](_attachments/RaspbianHistory/repos.png
"repository progress")

Figure shows a plot of the ratio of packages built in the repository to
the total in the Debian Wheezy repository. The ticks along the x-axis
mark the date of the first post and then the arrival of the fifth,
tenth, ..., new poster.

from 89 unique authors. The median number of posts per author was 2.
