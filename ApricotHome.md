# Apricot

-----

Started by Mike Thompson, Apricot is the adaptation of
[RaspBian](/RaspBian) to the APC hardware.

## Apricot Images

First, it was the Apricot Images. The documentation and files can be
found at the [Apricot Images](http://www.raspbian.org/ApricotImages)
page.

## Apricot Installer

Based on the [RaspBian installer](RaspbianInstaller), made by Jerry.tk,
it has been adapted to the hardware of the APC. For now, it able to
install Apricot on SD Card or USB Media. In a near future, it will be
able to install in the Internal Flash NAND memory. The Documentation and
files will be found at the [Apricot
Installer](http://www.raspbian.org/ApricotInstaller) page.
